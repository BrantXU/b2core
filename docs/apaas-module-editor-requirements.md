# aPaas平台模块编辑功能需求文档

## 1. 功能概述

aPaas（Application Platform as a Service）平台模块编辑功能是一个可视化的配置界面，允许用户通过拖拽和配置控件的方式来创建和编辑模块表单。该功能采用左右分栏设计，左侧显示所有可用控件并支持拖拽排序，右侧显示选中控件的属性配置菜单。

## 2. 用户界面设计

### 2.1 整体布局
- **左侧面板**（1/3宽度）：控件列表区域
- **右侧面板**（2/3宽度）：属性配置区域
- **顶部工具栏**：批量操作按钮和功能入口

### 2.2 左侧控件列表
- 显示当前模块的所有控件
- 每个控件项包含：
  - 拖拽手柄（可拖动排序）
  - 控件名称
  - 控件类型图标
  - 列宽信息
- 支持点击选择控件
- 支持拖拽重新排序
- 视觉反馈：悬停效果、选中状态高亮
- 控件根据宽度属性自动调整列宽

### 2.3 右侧属性面板
- 显示当前选中控件的详细属性
- 属性表单包含：
  - 基础属性（ID、名称、类型、列宽等）
  - 显示属性（是否列表显示、是否必填、只读等）
  - 高级属性（根据控件类型动态显示）
  - 保存和删除按钮

## 3. 核心功能需求

### 3.1 控件管理
- **控件类型支持**：
  - 文本输入（text）
  - 数字输入（number）
  - 日期选择（datepicker）
  - 下拉选择（select）
  - 文本区域（textarea）
  - 分区标题（section）
  - 标签页（tab）
  - 金额输入（yuan）
  - 百分比（percent）
  - 数量输入（amount）

- **控件操作**：
  - 添加新控件（通过创建配置）
  - 编辑控件属性
  - 删除控件
  - 拖拽排序

### 3.2 属性配置
- **基础属性**（所有控件通用）：
  - 控件ID（自动生成，只读）
  - 控件名称（必填）
  - 控件类型（下拉选择）
  - 列宽（1-4列选择）
  - 是否在列表中显示（复选框）
  - 是否必填（复选框）
  - 是否只读（复选框）
  - 提示信息（文本输入）

- **类型特定属性**（根据控件类型动态显示）：
  - 数字控件：最小值、最大值、步长
  - 日期控件：最小日期、最大日期
  - 下拉控件：选项列表配置
  - 文本区域：行数、列数
  - 金额控件：精度、最小值
  - 百分比控件：精度、范围

### 3.3 拖拽排序
- 使用UIkit Sortable组件实现拖拽功能
- 拖拽手柄可视化
- 实时保存排序结果
- 支持键盘辅助操作（可选）

### 3.4 数据持久化
- 配置数据存储为JSON格式
- 支持版本历史记录
- 实时自动保存（或手动保存）
- 错误处理和恢复机制

## 4. 技术实现

### 4.1 前端技术栈
- **UI框架**：UIkit 3.x
- **图标库**：Ionicons
- **拖拽库**：UIkit Sortable
- **JavaScript**：ES6+，模块化设计
- **样式**：CSS3，响应式设计

### 4.2 后端接口
需要实现以下API端点：

```javascript
// 获取配置数据
GET /{tenant_id}/config/get/{config_id}

// 更新控件属性  
POST /{tenant_id}/config/update_widget
{
    config_id: string,
    widget_id: string,
    name: string,
    type: string,
    width: number,
    listed: boolean,
    required: boolean,
    readonly: boolean,
    tips: string,
    props: object
}

// 更新控件排序
POST /{tenant_id}/config/update_order
{
    config_id: string,
    widget_order: string[]
}

// 删除控件
POST /{tenant_id}/config/delete_widget
{
    config_id: string,
    widget_id: string
}
```

### 4.3 数据结构

**控件配置结构**：
```json
{
  "widget_id": {
    "id": "string",
    "name": "string",
    "type": "text|number|datepicker|...",
    "width": 1,
    "listed": true,
    "required": false,
    "readonly": false,
    "tips": "提示信息",
    "props": {
      "min": 0,
      "max": 100,
      "options": "值1|显示1\n值2|显示2"
    }
  }
}
```

**配置文件结构**：
```json
{
  "_id": "config_id",
  "_key": "config_key", 
  "_type": "module",
  "_version": 1,
  "widgets": {
    "widget1": {...},
    "widget2": {...}
  },
  "widget_order": ["widget1", "widget2"],
  "metadata": {
    "created_at": "2024-01-01T00:00:00Z",
    "updated_at": "2024-01-01T00:00:00Z",
    "author": "user_id"
  }
}
```

## 5. 用户体验要求

### 5.1 交互反馈
- 拖拽时的视觉反馈
- 保存成功/失败的提示信息
- 加载状态的指示器
- 错误信息的友好展示

### 5.2 响应式设计
- 支持桌面端和移动端
- 自适应不同屏幕尺寸
- 触摸设备友好的交互

### 5.3 无障碍访问
- 键盘导航支持
- 屏幕阅读器兼容
- 高对比度模式支持

## 6. 性能要求

- 页面加载时间：< 3秒
- 操作响应时间：< 100ms
- 同时支持编辑的控件数量：50+
- 拖拽排序的流畅性

## 7. 安全要求

- 权限验证：只有授权用户才能编辑配置
- 数据验证：前后端双重验证
- XSS防护：输入内容过滤和转义
- CSRF防护：令牌验证机制

## 8. 浏览器兼容性
